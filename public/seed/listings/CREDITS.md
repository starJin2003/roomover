# Listing photo credits

The seed listings for Lakeshore University use the photos in this folder. Each one carries the Creative Commons CC0 1.0 Universal public domain dedication (https://creativecommons.org/publicdomain/zero/1.0/), so the repository can ship them with no attribution requirement. Credit is given here anyway. Every file was converted to JPEG, scaled to at most 1200 pixels on the long edge, and stripped of embedded metadata. Files marked as cropped were trimmed to frame the item and leave out unrelated text and artwork.
