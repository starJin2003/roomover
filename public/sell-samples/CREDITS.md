# Sell sample photo credits

Sell offers these photos so anyone can try listing an item without a camera. None of the items is in the seed catalog. Each photo carries the Creative Commons CC0 1.0 Universal public domain dedication (https://creativecommons.org/publicdomain/zero/1.0/), so the repository can ship them with no attribution requirement. Credit is given here anyway. Every file was cropped to frame the item, scaled to at most 1200 pixels on the long edge, and saved again as JPEG with no embedded metadata.
